# 收藏夹整理师 · Markdown 输出模板

Agent 在提炼内容后，按以下模板输出标准 Markdown 笔记。统一结构便于日后检索与回顾。

---

## 一、文字类模板（知乎 / 微信公众号）

```markdown
# {标题}

> 来源：{平台名} · {作者} · 发布于 {日期}
> 原文：{url}

## 核心观点

- {观点 1：一句话概括作者的主要论点}
- {观点 2}
- {观点 3}

### {子主题 A}
{展开说明，必要时用 `>` 引用原文关键句，并标注「—— 原文」}

### {子主题 B}
{...}

## 高赞补充

> **@{昵称}**（{赞同数} 赞）：{高赞评论核心内容}

> **@{昵称}**（{赞同数} 赞）：{...}

## 我的标签
#收藏整理 #{平台} #{主题分类}
```

---

## 二、视频类模板（小红书 / 微信视频号）

```markdown
# {视频标题}

> 来源：{平台名} · UP主/作者：{作者} · 时长 {MM:SS}
> 原链接：{url}
> 逐字稿：{transcript 文件相对路径，可选}

## 重点
- {核心结论 1}
- {核心结论 2}
- {金句 / 关键数据}

## 步骤
1. {步骤 1}
2. {步骤 2}
3. {步骤 3}

## 清单
- [ ] {要点 / 待办 1}
- [ ] {要点 / 待办 2}

## 关键帧（带时间戳）
- [00:45] {这一段讲了什么}
- [03:12] {这一段讲了什么}
- [08:30] {这一段讲了什么}

## 我的标签
#收藏整理 #{平台} #{主题分类}
```

> 说明：
> - **视频号** 必须保留「关键帧（带时间戳）」一节，方便回跳。
> - **小红书** 若无明显步骤，可省略「步骤」；图文笔记则直接抓取正文+图片OCR文字。
> - 时间戳格式统一为 `[MM:SS]`（超过 1 小时用 `[HH:MM:SS]`）。
```

---

## 三、文件名与目录约定

| 场景 | 路径 |
|------|------|
| 单次（用户指定目录） | `{dir}/{平台}_{标题前20字}.md` |

标题中的非法文件名字符（`/ \ : * ? " < > |`）替换为 `_`。
