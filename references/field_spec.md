# 收藏夹整理师 · 各平台字段抓取规范

说明各平台可提取的字段、清洗规则与注意事项，确保 Agent 提炼时信息完整、不编造。

---

## 知乎（文字类）

| 字段 | 来源 | 备注 |
|------|------|------|
| title | `h1` / `.QuestionHeader-title` | 问题标题 |
| author | `.AuthorInfo-name` | 回答者 |
| publish_time / 赞同 | `.VoteButton--up` 的 content | 近似发布时间 |
| content | `.RichText` 段落 | **去除** `.Advert`、推广卡片 |
| top_comments | `.CommentItem` 按点赞排序 | 取前 5，含昵称+点赞数 |

清洗重点：
- 删除「相关推荐」「更多回答」「盐选会员」推广块
- 仅保留高赞评论；与主题无关的闲聊评论丢弃
- 多回答的 question 页：每个高赞回答单独成「核心观点」子节

---

## 微信公众号（文字类）

| 字段 | 来源 | 备注 |
|------|------|------|
| title | `#activity-name` | 文章标题 |
| author | `#js_name` | 公众号名 |
| publish_time | `var ct = <unix时间戳>` | 需转换 |
| content | `#js_content` 段落 | 去除 script/style/二维码引流 |
| top_comments | `#js_comment` | 精选留言（如有） |

清洗重点：
- 删除「阅读原文」引导、二维码图片描述、关注卡片
- 保留作者核心逻辑 + 高赞留言（精选留言即"高赞补充"）

---

## 小红书（视频 / 图文）

- **视频**：`download_media.sh` → `extract_audio.sh` → `transcribe.sh` → 提炼（重点/步骤/清单）
- **图文**：抓取正文 + 图片（数量有限），对图片做 OCR（可调用多模态能力）后并入正文
- 注意：小红书反爬强，链接常失效；失败则提示用户直接发文件/截图

---

---

## 微信视频号（视频类）

- **无官方下载 API**。优先方案：用户把视频文件直接发给我（Agent）
- 收到文件后：`extract_audio.sh` → `transcribe.sh` → 提炼（同视频类模板，保留时间戳）
- 若用户只给链接且无法下载：如实说明限制，不强行抓取

---

## 通用安全与合规

1. 不抓取付费墙 / 明确禁止爬取内容
2. 遇到验证码 / 登录墙：停止并提示用户，不编造内容
3. 下载媒体仅用于个人笔记，不二次分发
4. 处理完毕可提示用户清理 `downloads/` 临时文件
